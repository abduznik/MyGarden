# Git Setup and Troubleshooting Steps (Manual Terminal Commands)

This document outlines the steps taken to resolve issues with `npm install` and `git push` in your project, specifically for a Termux/Android environment.

## 1. Install Node.js Dependencies

Initially, `npm install` failed due to permission issues with symlinks and `esbuild` post-install scripts. We bypassed these by:

```bash
npm install --no-bin-links --ignore-scripts
```
*   `--no-bin-links`: Prevents npm from creating symlinks for executables, which can cause permission issues on some file systems.
*   `--ignore-scripts`: Prevents npm from running post-install scripts (like `esbuild`'s), which were also causing permission errors.

## 2. Resolve Git Dubious Ownership

When running `quartz sync` (or any git command that interacts with the repository), you might encounter "dubious ownership" errors. This is a security feature of Git.

```bash
git config --global --add safe.directory /storage/emulated/0/Documents/mygarden
```
*   This command tells Git that the specified directory is safe to operate in, even if its ownership is not strictly conventional.

## 3. Configure Git User Identity

Git requires a user name and email to associate with your commits.

```bash
git config --global user.name "abduznik"
git config --global user.email "cloudbacho@gmail.com"
```
*   Replace `"abduznik"` and `"cloudbacho@gmail.com"` with your actual Git username and email.

## 4. Switch Git Remote to SSH

Initially, your remote was set to HTTPS, which often requires repeated password/token entry. We switched to SSH for more secure and convenient authentication using SSH keys.

First, verify your current remote:
```bash
git remote -v
```

Then, set the remote URL to use SSH:
```bash
git remote set-url origin git@github.com:abduznik/mygarden.git
```
*   Replace `abduznik/mygarden.git` with your actual GitHub username and repository name if different.

## 5. Generate and Add SSH Key to GitHub

To authenticate with GitHub via SSH, you need an SSH key pair.

### a. Generate SSH Key

```bash
ssh-keygen -t ed25519 -f ~/.ssh/id_ed25519 -q -N "" -C "cloudbacho@gmail.com"
```
*   `-t ed25519`: Specifies the encryption algorithm (Ed25519 is recommended).
*   `-f ~/.ssh/id_ed25519`: Specifies the file path for the key (default location).
*   `-q`: Quiet mode (suppresses output).
*   `-N ""`: Sets an empty passphrase (for convenience; for higher security, use a passphrase).
*   `-C "cloudbacho@gmail.com"`: Adds a comment to the key (usually your email).

### b. Get Public Key Content

```bash
cat ~/.ssh/id_ed25519.pub
```
*   Copy the **entire output** of this command.

### c. Add Public Key to GitHub

1.  Go to your GitHub account settings in a web browser.
2.  Navigate to "SSH and GPG keys".
3.  Click "New SSH key" or "Add SSH key".
4.  Provide a descriptive title.
5.  Paste the copied public key content into the "Key" field.
6.  Click "Add SSH key".

## 6. Add GitHub to Known Hosts

Sometimes, your SSH client might not recognize GitHub's host key, leading to "Host key verification failed" errors.

```bash
ssh-keyscan github.com >> ~/.ssh/known_hosts
```
*   This command fetches GitHub's SSH host key and appends it to your `~/.ssh/known_hosts` file, telling your SSH client to trust GitHub.

## 7. Push Changes to GitHub

After all the above steps, you can finally push your local commits to your GitHub repository.

```bash
git push
```
*   This command pushes the changes from your current branch to the remote repository.

**Note on `quartz sync`:**
The `npx quartz sync` command was initially attempted but failed due to various environment-specific issues. We then directly executed the Quartz CLI script using `node quartz/bootstrap-cli.mjs sync`. However, the core `git push` issues were resolved independently of the `quartz` command itself.
